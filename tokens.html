토큰

라이브러리 변수 Tokens 컬렉션이에요. 이름보다 용도로 골라요. 값은 라이트 모드 기준이에요.

Color Contrast

글자·아이콘 토큰이 바탕 위에서 잘 읽히는지예요. 브랜드 민트 계열은 밝아서 흰 바탕 위 글자, 민트 위 흰 글자 모두 대비가 낮아요. 바꿀지는 디자인 시스템에서 따로 정해요. 기준 WCAG AA: 작은 글자 4.5 이상, 큰 글자(18px 이상 또는 굵은 14px 이상)·아이콘 3 이상.

Token Files

토큰 값을 파일로 받을 수 있어요. 앱 코드는 앱에 이미 있는 상수를 쓰고, 이 파일은 값 확인이나 링크용 화면(웹)에 써요.

tokens.json디자인 토큰 표준 형식 (DTCG)tokens.css웹 · CSS 변수
틀린 내용이 있거나 필요한 부품·토큰이 없으면 디자인 시스템 담당자에게 알려 주세요. 사이트와 피그마가 다르면 피그마가 기준이에요.
