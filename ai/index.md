# TEUIDA 디자인 시스템

TEUIDA 앱 화면을 만들 때 보는 기준이에요. 디자이너, 개발자, 그리고 팀원이 쓰는 Claude가 같은 내용을 읽어요.

- **이 사이트는 읽는 곳이에요.** 화면 작업은 피그마에서 해요. 피그마에 시안을 만들려면 피그마 편집 권한이 있어야 해요.
- 원본은 피그마 라이브러리(Design Library)예요. 사이트와 피그마가 다르면 **피그마가 기준**이에요.
- 마지막 갱신: 2026-11-06

## 누가 어떻게 쓰나

| 누가 | 어디서 작업 | 이 사이트에서 볼 것 |
|---|---|---|
| 디자이너 | 피그마 (편집 권한 필요) | [작업 규칙](rules.html) → [컴포넌트](components.html)에서 고르기 → [디스크립션](description.html) |
| 개발자 | 앱 코드 | [컴포넌트](components.html)의 "스펙 보기" (크기·여백·부분별 토큰·배리언트별 차이) + [토큰](tokens.html) |
| 팀원·개발자의 Claude | 앱 코드, 링크용 화면 등 | [`llms.txt`](llms.txt) → Markdown 문서와 `data/components.json` ([Claude용 안내](ai.html)) |

## 꼭 지킬 것

1. **라이브러리 부품만 써요.** 인스턴스를 떼어내거나(detach) 로컬 부품을 새로 만들지 않아요. 맞는 게 없으면 가장 가까운 걸 쓰고 알려요.
2. **색은 용도 토큰, 글자는 텍스트 스타일, 간격·모서리는 토큰.** hex 값이나 임의 숫자를 직접 넣지 않아요.
3. **단, 콘텐츠가 한 화면에 다 들어가는 게 간격보다 먼저예요.** 학습 화면은 스크롤하지 않아요.
4. **글자가 들어간 알약(완전히 둥근) 버튼은 쓰지 않아요.** 글자 버튼은 모서리 8이에요.
5. **이 사이트 [컴포넌트](components.html)에 있는 것만 써요.** 피그마에서 찾았는데 여기 없으면 쓰지 않고 담당자에게 알려요.

## 작업 순서

1. **현행 화면에서 시작해요.** [현행 화면](screens.html)(피그마 `🧩 기능별 최신 화면`과 같아요)에서 해당 기능 원본을 찾아 시작해요. 섹션 안 화면만 원본이에요. 섹션 밖 화면은 참고용이에요. A/B 테스트 중인 화면은 빼요. 원본이 없으면 [화면 뼈대](components.html#T)에서 시작해요.
2. **부품을 골라요.** [컴포넌트](components.html) 페이지에서 "언제 / 쓰지 말 것"을 보고 골라요. 이 페이지에 없는 부품은 쓰지 않아요.
3. **인스턴스로 놓아요.** detach하지 않아요.
4. **색·글자·간격·모서리를 토큰과 스타일에 연결해요.** → [토큰](tokens.html)
5. **콘텐츠가 한 화면에 들어가는지 봐요.** 넘치면 간격부터 줄여요.
6. **화면을 보고 확인해요.** 토큰이 안 걸린 곳, 로컬 부품, 사이트에 없는 부품이 없는지 봐요.
7. **디스크립션을 화면마다 달아요.** → [디스크립션](description.html)
